# JK Story Virtual 3D 첫 직원 채용·배치안

상태: 1차 가상 직원 프로필 확정안. `채용`은 이 프로젝트 안에서 역할·보고선·업무 범위를 부여하는 뜻입니다. 실제 Claude Code·Hermes의 하위 에이전트 생성이나 계정 연결이 끝났다는 뜻은 아닙니다.

## 조직과 보고선

Codex·Claude Code·Hermes는 각 팀의 책임자입니다. 전담비서는 세 팀보다 위에 있는 관리자가 아니라 대표 지시를 전달하고 결과를 취합하는 단일 접점입니다. 직원별 주담당 책임자는 한 명이며, 다른 팀은 검토 또는 지원으로 참여합니다.

## 채용 순서

1. 1차: 전담비서와 여섯 실무 직원의 프로필, 좌석, 보고선, 업무 권한을 가상 사무실에 등록합니다.
2. 2차: 공용 업무 저장소와 감사 로그를 만든 뒤 비서 접수→담당 배정→결과 보고를 실제 데이터로 시험합니다.
3. 3차: 각 에이전트의 사용 가능한 실행 도구와 권한을 연결합니다. 연결 확인 전 직원 상태는 `배치 예정` 또는 `연결 대기`로 표시합니다.
4. 4차: 개인정보 없는 가상 업무를 통과한 팀부터 JKSTORY 실제 시스템의 조회 업무에 연결하고, 변경·발송은 별도 권한과 기록을 갖춘 뒤 시작합니다.

## 대표가 보게 될 직원 카드

직원명/직책, 소속 팀, 보고 대상, 맡은 업무, 현재 연결 상태, 진행 중인 업무 수, 최근 실행 근거를 표시합니다. 실행 근거가 없는 직원은 `업무 수행 중`으로 표시하지 않습니다.

이 구성은 시험 결과에 따라 증원·통합할 수 있습니다. 센터마다 별도 직원이 필요한지는 실제 업무량과 권한 분리를 확인한 뒤 결정합니다.
